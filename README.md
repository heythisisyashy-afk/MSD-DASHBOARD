# 🏏 MS Dhoni Career Analytics Dashboard

## 📌 Project Overview

The MS Dhoni Career Analytics Dashboard is a Sports Analytics project developed using Power BI. This dashboard provides a comprehensive analysis of MS Dhoni's cricket career across multiple formats, helping users explore performance trends, career statistics, and key achievements through interactive visualizations.

The objective of this project is to demonstrate how data analytics and business intelligence can be applied in sports to transform raw data into meaningful insights and support data-driven decision-making.

---

## 🎯 Project Objectives

- Analyze MS Dhoni's career performance using cricket statistics.
- Track key performance indicators (KPIs) such as Runs, Matches, Average, and Strike Rate.
- Compare performance across different cricket formats.
- Identify trends through year-wise performance analysis.
- Create an interactive and visually appealing Sports Analytics dashboard.
